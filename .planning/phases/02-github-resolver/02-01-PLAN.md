  <behavior>

    - auth_discover_token_from_env_empty: when GITHUB_TOKEN is empty string, falls through to next method
    - auth_discover_unauthenticated: when no env var and no gh CLI, returns None with AuthMethod::Unauthenticated
    - tree_response_deserialize: TreeResponse JSON deserializes correctly with tree entries containing path, type (renamed from "type"), sha
    - repo_info_deserialize: RepoInfo JSON deserializes correctly with default_branch field
    - tree_entry_type_field: TreeEntry correctly handles serde rename of "type" to entry_type
  </behavior>
  <action>
    1. Add reqwest to Cargo.toml: `reqwest = { version = "0.12", features = ["blocking", "json"] }`

    2. Add new error variants to src/error.rs:
       - `RateLimited { remaining: u64, reset_epoch: Option<i64> }` with diagnostic code `skills_sync::github::rate_limited` and help text showing remaining count, reset time (formatted from epoch), and auth hint
       - `GitHubApi { status: u16, message: String, repo: String }` with diagnostic code `skills_sync::github::api_error`
       - `RepoNotFound { repo: String }` with diagnostic code `skills_sync::github::repo_not_found` and help to check repo name/access
       - `NetworkError { repo: String, reason: String }` with diagnostic code `skills_sync::github::network`
       - `HttpClient(String)` wrapping reqwest errors — use `#[error("HTTP client error: {0}")]` (don't use `#[from] reqwest::Error` because reqwest::Error doesn't implement miette::Diagnostic)

    3. Create src/github.rs with:
       - `AuthMethod` enum: `EnvVar`, `GhCli`, `Unauthenticated`
       - `discover_token() -> (Option<String>, AuthMethod)` — tries GITHUB_TOKEN env var, then `gh auth token` subprocess, then unauthenticated. Returns tuple of optional token and method used.
       - `TreeEntry` struct: path (String), entry_type (String, serde rename from "type"), sha (String)
       - `TreeResponse` struct: sha (String), tree (Vec<TreeEntry>), truncated (bool)
       - `RepoInfo` struct: default_branch (String)
       - `GitHubClient` struct: client (reqwest::blocking::Client), token (Option<String>), auth_method (AuthMethod)
       - `GitHubClient::new(token: Option<String>, auth_method: AuthMethod) -> Result<Self>` — builds reqwest Client with user_agent("skills-sync/{version}") using env!("CARGO_PKG_VERSION"), stores token and auth_method
       - `GitHubClient::get_repo_info(&self, owner: &str, repo: &str) -> Result<RepoInfo>` — calls GET /repos/{owner}/{repo}, handles 404 as RepoNotFound, rate limit as RateLimited, other errors as GitHubApi
       - `GitHubClient::get_tree(&self, owner: &str, repo: &str, branch: &str) -> Result<TreeResponse>` — calls GET /repos/{owner}/{repo}/git/trees/{branch}?recursive=1, same error handling
       - Private helper `check_rate_limit(response: &reqwest::blocking::Response) -> Option<SkillsSyncError>` — parses x-ratelimit-remaining and x-ratelimit-reset headers from response, returns Some(RateLimited) if remaining is 0
       - Private helper `send_request(&self, url: &str) -> Result<reqwest::blocking::Response>` — adds Accept: application/vnd.github+json header, adds Authorization: Bearer {token} if token present, sends request, maps reqwest errors to NetworkError

    4. Add `pub mod github;` to src/lib.rs

    5. Write tests in tests/github_tests.rs:
       - Test discover_token with GITHUB_TOKEN env var set (use temp env manipulation)
       - Test TreeResponse deserialization from sample JSON
       - Test RepoInfo deserialization from sample JSON
       - Test TreeEntry correctly renames "type" field
       - Test GitHubClient::new creates client without error

    Note: Do not test actual HTTP calls (no mock server needed). Test auth discovery, type deserialization, and client construction only. Real API calls will be tested via integration in Plan 03.
