<objective>
Add --check flag to CLI for CI gate enforcement: exit 0 when skills are in sync, exit 1 when out of sync.

Purpose: Teams need a CI gate that fails the build when the manifest doesn't match reality. The --check flag performs a read-only diff (same pipeline as normal sync) and exits with an appropriate code without modifying anything. This enables `npx skills-sync --check` in CI pipelines.
Output: Working --check flag that exits 0/1, with diff preview on failure, mutual exclusion with --dry-run, and unit tests.
</objective>
