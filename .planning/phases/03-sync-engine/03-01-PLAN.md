           help("{stderr}")

<task type="auto" tdd="true">
  <name>Task 2: Implement execute_install, execute_update, and execute_remove with atomic directory operations</name>
  <files>src/sync.rs, tests/sync_tests.rs</files>
  <behavior>
    - execute_install_creates_target_dir: execute_install creates target_dir if it does not exist (via fs::create_dir_all)
    - execute_install_writes_metadata_after_rename: after successful install, .skills.lock exists inside final skill directory containing source, sha, and timestamps
    - execute_install_monorepo_sets_subdirectory: monorepo install writes SkillMeta with subdirectory field set
    - execute_update_preserves_installed_at: execute_update reads old metadata's installed_at, re-installs, then patches the new metadata to restore original installed_at
    - execute_remove_deletes_directory: execute_remove removes the skill directory via fs::remove_dir_all
    - execute_remove_nonexistent_returns_error: execute_remove on nonexistent path returns RemoveFailed error
  </behavior>
  <action>
    Implement the three core sync operations in src/sync.rs:

    1. `pub fn execute_install(repo: &str, subdirectory: &Option<String>, remote_sha: &str, branch: &str, target_dir: &Path, token: Option<&str>) -> crate::error::Result<()>`:

       - Compute `dir_name` via `skill_dir_name(repo, subdirectory)`
       - Compute `final_path = target_dir.join(&dir_name)`
       - Compute `tmp_name = format!(".skills-sync-tmp-{}-{}", std::process::id(), &dir_name)`
       - Compute `tmp_path = target_dir.join(&tmp_name)`
       - Call `std::fs::create_dir_all(target_dir)` to ensure target exists
       - Build clone URL via `build_clone_url(repo, token)`
       - Branch on subdirectory:
         - **None (single-skill):**
           - `run_git(&["clone", "--depth=1", "-b", branch, "--", &clone_url, tmp_path_str], None)?`
           - `std::fs::rename(&tmp_path, &final_path)` wrapped in RenameFailed error
         - **Some(subdir) (monorepo):**
           - `run_git(&["clone", "--depth=1", "--no-checkout", "--filter=blob:none", "--", &clone_url, tmp_path_str], None)?`
           - `run_git(&["sparse-checkout", "init", "--cone"], Some(&tmp_path))?`
           - `run_git(&["sparse-checkout", "set", subdir], Some(&tmp_path))?`
           - `run_git(&["checkout"], Some(&tmp_path))?`
           - `std::fs::rename(tmp_path.join(subdir), &final_path)` — moves only subdirectory out
           - `std::fs::remove_dir_all(&tmp_path)` — clean up temp clone (has .git and root files)
       - After rename succeeds, write metadata:
         - `let meta_path = final_path.join(META_FILENAME);`
         - Build `SkillMeta::new(repo, remote_sha)`, chain `.with_subdirectory(subdir)` if monorepo
         - `write_metadata_atomic(&meta_path, &meta)?`
       - If any git command fails, attempt cleanup of tmp_path (best-effort `let _ = fs::remove_dir_all(&tmp_path)`) before returning the error
       - Use `map_err` to convert io::Error from rename into `SkillsSyncError::RenameFailed`

    2. `pub fn execute_update(repo: &str, subdirectory: &Option<String>, new_sha: &str, branch: &str, target_dir: &Path, token: Option<&str>) -> crate::error::Result<()>`:

       - Compute `dir_name` and `existing_path = target_dir.join(&dir_name)`
       - Read old metadata to preserve installed_at:
         ```rust
         let old_meta_path = existing_path.join(crate::metadata::META_FILENAME);
         let installed_at = crate::metadata::read_metadata(&old_meta_path)
             .ok()
             .map(|m| m.installed_at)
             .unwrap_or_else(|| chrono::Utc::now());
         ```
       - Remove old directory: `fs::remove_dir_all(&existing_path)` wrapped in RemoveFailed
       - Call `execute_install(repo, subdirectory, new_sha, branch, target_dir, token)?`
       - Patch installed_at back:
         ```rust
         let meta_path = target_dir.join(&dir_name).join(crate::metadata::META_FILENAME);
         if let Ok(mut meta) = crate::metadata::read_metadata(&meta_path) {
             meta.installed_at = installed_at;
             let _ = crate::metadata::write_metadata_atomic(&meta_path, &meta);
         }
         ```

    3. `pub fn execute_remove(skill_path: &Path) -> crate::error::Result<()>`:
       - `std::fs::remove_dir_all(skill_path).map_err(|e| SkillsSyncError::RemoveFailed { path: skill_path.to_owned(), source: e })?`
       - Return Ok(())

    4. Add integration-style tests to tests/sync_tests.rs (using tempdir for filesystem tests, no actual git calls needed for pure fs tests):
       - Test execute_remove on a manually created temp directory succeeds
       - Test execute_remove on nonexistent path returns error
       - Test that skill_dir_name produces correct paths for both single and monorepo cases (already covered in Task 1, extend if needed)

    Note: execute_install and execute_update require a real git binary and network access, so their full integration testing happens via `cargo run` against real repos. The unit tests here cover the filesystem and metadata aspects using manually created directories.
