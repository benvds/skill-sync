  <name>Task 1: Implement reporter and executor modules</name>
  <files>src/reporter.ts, src/executor.ts, test/reporter.test.ts, test/executor.test.ts</files>
  <behavior>
    - reporter.printSummary(2, 3) outputs "2 installed, 3 unchanged"
    - reporter.printDryRunSummary(2, 3) outputs "2 to install, 3 unchanged (dry run)"
    - reporter.printAction('installing', 'owner/repo') outputs symbol + source
    - reporter.printError(message, hint) outputs error with hint below
    - executeSync in dry-run mode does NOT call execa — just prints commands
    - executeSync calls npx skills add <source> --yes for each source
    - executeSync adds --global flag when scope is global
    - executeSync continues on failure (warns, does not abort)
    - executeSync returns SyncResult with installed/failed/unchanged counts
  </behavior>
  <action>
1. Create src/reporter.ts (from RESEARCH.md Reporter pattern):
   - Use picocolors for all color output
   - Status symbols: checkmark (green, present/done), cross (red, error), down-arrow (cyan, installing), circle (dim, pending) — per locked decision
   - `printAction(type: 'installing' | 'skipped', source: string)` — status symbol + source name
   - `printSuccess(source: string)` — green checkmark + source
   - `printUnchanged(source: string)` — dim checkmark + source
   - `warnSourceFailed(source: string, reason: string)` — red cross + source + reason
   - `printCommand(cmd: string)` — dim command text (plumbing for --verbose in Phase 2)
   - `printDryRunCommand(cmd: string)` — prefixed with "(dry run)" in dim
   - `printSummary(installed: number, unchanged: number)` — bold "X installed, Y unchanged"
   - `printDryRunSummary(toInstall: number, unchanged: number)` — bold "X to install, Y unchanged" + dim "(dry run)"
   - `printError(message: string, hint: string)` — red "Error:" + message, dim "Hint:" + hint
   - `warnLockVersionMismatch(actual: number, expected: number)` — yellow warning
   - `warnLockFileCorrupt(path: string)` — yellow warning

2. Create test/reporter.test.ts:
   - Test that printSummary outputs correct format (mock console.log, verify string content)
   - Test that printDryRunSummary includes "(dry run)"
   - Test that printError outputs both message and hint

3. Create src/executor.ts (from RESEARCH.md Pattern 3):
   - `executeSync(diff: Diff, options: SyncOptions): Promise<SyncResult>` — the single entry point
   - For each source in diff.toAdd:
     - Print "installing" action via reporter
     - Build args: `['skills', 'add', source, '--yes']`
     - If scope is global: push `'--global'` to args
     - Always show the command being run via reporter.printCommand (plumbing for --verbose)
     - If dryRun: call reporter.printDryRunCommand, skip execa, count as "would install"
     - If not dryRun: call `execa('npx', args, { stdout: 'inherit', stderr: 'inherit' })`
     - On success: call reporter.printSuccess, increment installed count
     - On failure (ExecaError): call reporter.warnSourceFailed, increment failed count, CONTINUE (per locked decision)
   - For each source in diff.unchanged: call reporter.printUnchanged
   - Return SyncResult { installed, failed, unchanged: diff.unchanged.length }

4. Create test/executor.test.ts:
   - Test dry-run mode: verify execa is NOT called, reporter.printDryRunCommand IS called
   - Test that args include --yes always
   - Test that args include --global when scope is global
   - Test that failure on one source doesn't abort remaining sources
   - Mock execa to avoid real subprocess calls in tests
  </action>

<task type="auto">
  <name>Task 2: Wire CLI entry point with commander</name>
  <files>bin/skills-sync.ts</files>
  <action>
1. Create bin/ directory if needed.

2. Create bin/skills-sync.ts (from RESEARCH.md Commander Setup):
   - Shebang: `#!/usr/bin/env node`
   - Import commander, all src modules
   - Set up program with commander:
     - name: "skills-sync"
     - description: "Declarative skill management: commit .skills.toml, run npx skills-sync"
     - version: read from package.json (import with assert { type: 'json' } or use createRequire)
     - Options: --global, --local, --dry-run, --init, --config <path>
     - -h/--help and -V/--version handled by commander automatically

3. Main action handler:
   a. Mutual exclusion check: if both --global and --local, print error and exit(1) — per FLAG-01
   b. Determine scope: `const scope = options.global ? 'global' : 'local'` (default local)
   c. If --init: call writeManifestTemplate(scope), print success message with path, exit(0)
   d. Sync pipeline:
      - `const manifest = await readManifest(options.config, scope)`
      - `const state = scope === 'global' ? await readGlobalState() : await readLocalState()`
      - `const diff = computeDiff(manifest, state)`
      - If diff.toAdd.length === 0 and not dryRun: print "Everything up to date" + summary, exit(0)
      - `const result = await executeSync(diff, { scope, dryRun: options.dryRun ?? false })`
      - If dryRun: reporter.printDryRunSummary(diff.toAdd.length, diff.unchanged.length)
      - Else: reporter.printSummary(result.installed, result.unchanged)
      - If result.failed > 0: exit(1) — some sources failed

4. Top-level error handler wrapping the action:
   - If SkillsSyncError: reporter.printError(err.message, err.hint), exit(1)
   - If unknown error: reporter.printError(err.message, 'This is an unexpected error'), exit(1)

5. Call `program.parse()` at the end.

6. Verify the build works: `npx tsup` should produce dist/skills-sync.js with shebang.
